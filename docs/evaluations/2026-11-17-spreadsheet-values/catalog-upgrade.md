# 旧工作区工具版本升级修复

用户随后反馈 `Tool version is not available for binding.`。只读检查确认：本地数据库虽已升级到 `202611160006`，两个旧工作区的 bash 仍指向旧的内容哈希版本。创建 Run 时，隐式 bash 使用当前代码生成的新版本 ID，绑定检查因目录版本不同而返回 422。首次真实模型评测使用新建数据库，未覆盖这个升级场景。

新增 `202611170001_builtin_file_delivery_catalog.py` 兼容迁移，刷新现有 bash、图片和四个固定文件工具的不可变版本、当前指针及策略指纹。审批模式、访问来源、风险分类、禁用/不可用状态等管理设置保持原样。此次输入契约保持兼容，只有描述及附加交付元数据变化；原先绑定升级前当前版本的可变应用绑定随之更新。

旧版本记录、已发布配置和 Run 快照不改写。原本就指向更老版本的过期绑定不自动升级；需要用户编辑对应 Agent、重新选择工具并保存。已发布 Agent 若要使用更新后的固定工具，需要按正常流程重新发布。现有运行不会被改写成使用新版本；部署时应先让执行中的 Run 结束。
