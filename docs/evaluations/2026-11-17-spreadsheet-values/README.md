# 表格数值交付修复与真实回归

2026-11-17，修复此前 CSV → XLSX 三轮任务把金额保存成无缓存公式、未满足存储数值要求的问题。原始失败证据保留在 [首次基线](../2026-11-17-deepseek-flash/README.md)，本次没有改动数据集或断言。

## 产品行为

- bash 与固定表格工具共用数值交付说明：用户要求金额、总额或可直接读取的数值时，先计算再写入数字，并用 openpyxl `data_only=True` 重新读取验证。固定表格 Skill 的操作说明同步更新。
- XLSX 文件检查增加 `details.uncached_formulas`，明确告知没有缓存结果的公式会在不重算的读取器中显示为空，并给出修正建议。缓存数值 `0` 正常计为已有结果。
- 用户明确要求公式时保留公式。检查器不计算、不修改工作簿；缺少缓存产生警告，不因合法公式而直接拒绝文件。工具规则和反馈用于让模型修正交付，不是隐藏的语义判断门禁。

规则随工具描述冻结到新 Run；旧 Run 的不可变配置保持原样。执行端检查和 Skill 文档需要构建并更新执行镜像，后端工具规则需要重启相应服务。本次只验证独立镜像与临时服务，尚未更新正式环境。
