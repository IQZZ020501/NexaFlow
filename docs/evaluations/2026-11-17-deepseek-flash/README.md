# DeepSeek 文件交付真实基线

2026-11-17，按用户授权新建临时 Agent，使用本地已配置的 DeepSeek 官方凭据。数据集为 `docs/examples/agent-delivery-evaluation.json`，断言未修改。使用普通 Docker OpenSandbox、隔离 PostgreSQL/Redis 和最新迁移，不升级业务数据库。

请求模型为 `deepseek-v4-flash`，供应商响应模型名为 `deepseek-flash`。官方价格页说明旧别名由 Flash 新版服务；响应没有给出具体版本号，因此不把文档中的版本标号当作本次响应直接证明的值。非思考模式，温度 0.2，每次最多输出 8192 tokens，每个 Run 最多 8 轮/8 次工具调用。临时 Agent 可用四个固定文件渲染工具和隐式 bash，采用明确授权的 `full_access`，没有外部工具或联网能力。

随后只修改临时 Agent 的通用数值交付约束：明确要求数值时在 Python 计算并写入 int/float，保存后用 `data_only=True` 检查，不依赖 Excel 打开后重算。`focused-retest.json` 的同一表格三轮断言全部通过，金额分别为 `36/40/76`、`48/40/88`、`48/50/98`。

复测使用了不同的 Agent 指令配置；**当时没有在新配置下重跑全部五类**，因此不能把首轮与定向复测合并成同一配置的 5/5 基线。该阶段未修改运行时、渲染器或测试断言来获得通过结果；当时的约束只用于临时评测 Agent。

随后按用户要求，将数值交付规则加入产品工具说明并增加无缓存公式检查反馈，使用本报告的原始中性 Agent 指令重新完整执行五类任务，结果为 5/5；详见 [产品修复与新回归](../2026-11-17-spreadsheet-values/README.md)。本目录保留原始失败与临时指令复测的历史记录。
